# 探究實驗室 · 模組 2：西芹的紅色水跡

繁體中文、四階段的 S4 生物探究式虛擬實驗室。沿用模組 1 的青綠卡片風格；不需要套件安裝或外部服務。

## 啟動

在現有 checkout 執行（毋須建立 Git worktree）：

```sh
cd /workspace/Transpiration
python -m http.server 8000 --bind 0.0.0.0
```

使用網站伺服器提供 `index.html`、`styles.css` 和 `app.js`。亦可部署至支援靜態網站的服務。直接開啟 HTML 的本機儲存行為因瀏覽器而異，建議使用 HTTP。

## 探究流程

1. 觀察情境、記錄原始觀察。
2. 提出預測，辨認變量、實驗假設，先記錄對照組想法，再查看提示；繪畫、上載或文字描述裝置。
3. 同步比較 A（10 cm，帶葉）、B（20 cm，帶葉）、C（30 cm，帶葉）、D（20 cm，不帶葉）。以尺量度 0、10、20、30 分鐘水跡高度。
4. 自行計算平均上移速度及繪圖、提出主張和證據。遞交後顯示蒸騰學習重點、參考回饋、反思及報告。

所有樣本浸入深度為 2 cm，固定溫度、濕度、氣流及其他指定條件。圖表為照度（lux）對紅色水跡平均上移速度（cm/min）；D 是獨立比較點，不與帶葉系列連線。

## 科學模型及研究用途

- 西芹長柄實際是葉柄；虛擬剖視不表示樣本被縱切。
- 照度及水跡是教學用模擬數據，並非經實驗校準的預測模型。每次新探究使用固定於該次紀錄的輕微樣本變異。
- 水跡上移速度不能直接等同蒸騰速率；無葉比較不能單獨證明氣孔的作用。
- 沒有加入移葉切口密封或質量量度操作。
- 設計與量度答案不因不符合預期而被阻止；參考回饋只在遞交後揭示。每輪首次確認讀數、原始設計及修改事件會保留。
- 原始觀察、變量分類、設計、假設、結論、反思適合人工 rubric 評分；操作次數不能直接當作 SPS 分數。

## 資料與匯出

資料僅儲存在目前瀏覽器的 localStorage，不會傳送至中央伺服器。使用研究編號或暱稱，毋須電郵或姓名。重新整理可恢復答案；背景分頁時間不計入有效操作時間。

- **列印／儲存 PDF**：開啟瀏覽器列印視窗，選擇「另存為 PDF」。收錄原始答案、假設及參考解釋、量度、計算、圖表、結論、反思。
- **下載研究紀錄**：完整 JSON，包括首次讀數、模型參考值、設計快照及事件。
- **學習紀錄**：整理本機紀錄、匯入學生 JSON，以及匯出真正 `.xlsx` 檔（答案、量度計算與圖點、事件三個工作表）。裝置繪圖保存在 JSON 及 PDF，Excel 以文字設計呈現。

學習紀錄頁沒有教師身分驗證；在共用瀏覽器上的紀錄會互相可見。正式研究請使用學校指定的安全提交及資料管理方式。瀏覽器清除資料將刪除本機紀錄，應另行下載備份。
