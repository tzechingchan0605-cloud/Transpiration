# 探究實驗室 · 模組 2：西芹的紅色水跡

繁體中文、四階段的 S4 生物探究式虛擬實驗室。沿用模組 1 的青綠卡片風格；不需要套件安裝或外部服務。

## 啟動

在現有 checkout 執行（毋須建立 Git worktree）：

```sh
cd /workspace/Transpiration
python -m http.server 8000 --bind 0.0.0.0
```

使用網站伺服器提供 `index.html`、`styles.css` 和 `app.js`。亦可部署至支援靜態網站的服務。直接開啟 HTML 的本機儲存行為因瀏覽器而異，建議使用 HTTP。

## 探究流程

1. 觀察情境、記錄原始觀察。
2. 提出預測、辨認變量、選出所有適用的實驗假設，說明對照裝置；根據材料清單自由繪畫、上載或文字描述裝置。不提供預設裝置答案。
3. 同步比較裝置A（10 cm，帶葉）、裝置B（20 cm，帶葉）、裝置C（30 cm，帶葉）、裝置D（20 cm，不帶葉）。量尺只能左右移動，零點固定在水面。量度 0、10、20、30 分鐘高度，讀數箭嘴每次增減 0.5 cm，輸入及保存為一位小數。手動輸入可至 0.1 cm；超過一位小數會被要求修正。
4. 自行計算平均上移速度；固定 X軸、Y軸和刻度，以自己的計算標點。光強度關係、葉片作用和實驗限制以選項填空回答。遞交後顯示葉與莖的內部構造圖、學習重點及反思，並顯示學生原始假說供對照。儲存並提交反思後，才可下載學習紀錄 PDF。

所有樣本浸入深度為 2 cm，固定溫度、濕度、氣流及其他指定條件。圖表為光強度（lux）對紅色水跡平均上移速度（cm/min）；裝置D 是獨立比較點，裝置A、裝置B、裝置C 使用通過學生圖點的平滑曲線。曲線只展示三點間的趨勢，不代表已驗證連續的精確關係。

每次按「繼續實驗 +10 分鐘」會捲動至裝置；確認量度後回到計時介面。0 分鐘有初始讀數提醒。

## 科學模型及研究用途

- 西芹長柄實際是葉柄；虛擬剖視不表示樣本被縱切。
- 光強度讀數及水跡是教學用模擬數據，並非經實驗校準的預測模型。光強度依課本用語呈現，以 lux 作為模擬光度計讀數。每次新探究使用固定於該次紀錄的輕微樣本變異，水跡高度以 0.5 cm 為模擬量度間距。
- 水跡上移速度不能直接等同蒸騰速率；無葉比較不能單獨證明氣孔的作用。
- 沒有加入移葉切口密封或質量量度操作。
- 設計與量度答案不因不符合預期而被阻止；參考回饋只在遞交後揭示。每輪首次確認讀數、原始設計及修改事件會保留。
- 原始觀察、變量分類、設計、假設、結論、反思適合人工 rubric 評分；操作次數不能直接當作 SPS 分數。
- 學習重點參照使用者提供課本 `te_11_c.pdf` 第 11.1 節（11-3 至 11-8 頁），採用水膜、氣室、水汽、木質導管、蒸騰拉力等術語。構造圖為自行繪製的教學示意，PDF 原檔沒有加入公開儲存庫。
