# 探究實驗室 · 模組 2：西芹的紅色水跡

繁體中文、四階段的 S4 生物探究式虛擬實驗室。沿用模組 1 的青綠卡片風格；不需要套件安裝或外部服務。

## 啟動

在現有 checkout 執行（毋須建立 Git worktree）：

```sh
cd /workspace/Transpiration
python -m http.server 8000 --bind 0.0.0.0
```

使用網站伺服器提供 `index.html`、`styles.css` 和 `app.js`。亦可部署至支援靜態網站的服務。直接開啟 HTML 的本機儲存行為因瀏覽器而異，建議使用 HTTP。

## 探究流程

1. 觀察情境、記錄原始觀察。
2. 提出預測、辨認變量、選出所有適用的實驗假設，說明對照裝置；根據材料清單自由繪畫、上載或文字描述裝置。不提供預設裝置答案。
3. 同步比較裝置A（10 cm，帶葉）、裝置B（20 cm，帶葉）、裝置C（30 cm，帶葉）、裝置D（20 cm，不帶葉）。量尺只能左右移動，零點固定在水面。量度 0、10、20、30 分鐘高度，讀數箭嘴每次增減 0.5 cm，輸入及保存為一位小數。手動輸入可至 0.1 cm；超過一位小數會被要求修正。
4. 自行計算平均上移速度（兩位小數）；固定 X軸、Y軸和刻度，以自己的計算標點。光強度關係、葉片作用和實驗限制以選項填空回答。遞交後顯示葉與莖的內部構造圖、學習重點及反思，並顯示學生原始假說供對照。儲存並提交反思後，才可下載學習紀錄 PDF。

所有樣本浸入深度為 2 cm，固定溫度、濕度、氣流及其他指定條件。圖表為光強度（lux）對紅色水跡平均上移速度（cm/min）；裝置D 是獨立比較點，裝置A、裝置B、裝置C 使用通過學生圖點的平滑曲線。曲線只展示三點間的趨勢，不代表已驗證連續的精確關係。

每次按「繼續實驗 +10 分鐘」會捲動至裝置；確認量度後回到計時介面。0 分鐘有初始讀數提醒。

## 科學模型及研究用途

- 西芹長柄實際是葉柄；虛擬剖視不表示樣本被縱切。
- 光強度讀數及水跡是教學用模擬數據，並非經實驗校準的預測模型。光強度依課本用語呈現，以 lux 作為模擬光度計讀數。每次新探究使用固定於該次紀錄的輕微樣本變異，水跡高度以 0.5 cm 為模擬量度間距。
- 水跡上移速度不能直接等同蒸騰速率；無葉比較不能單獨證明氣孔的作用。
- 沒有加入移葉切口密封或質量量度操作。
- 設計與量度答案不因不符合預期而被阻止；參考回饋只在遞交後揭示。每輪首次確認讀數、原始設計及修改事件會保留。
- 選擇題、讀數、速度計算與標點可依明確準則自動檢核；原始觀察、假說理由、裝置方案、書面表達及反思由教師按 rubric 評分。操作次數不能直接當作 SPS 分數。
- 學習重點參照使用者提供課本 `te_11_c.pdf` 第 11.1 節（11-3 至 11-8 頁），採用水膜、氣室、水汽、木質導管、蒸騰拉力等術語。構造圖為自行繪製的教學示意，PDF 原檔沒有加入公開儲存庫。

### 教師 Excel 評分（VL2 初稿）

分數只見於教師 Excel，不寫入學生 PDF 或學生介面。工作簿新增「教師評分」與「評分準則」，保留答案、量度、操作事件及裝置圖，共六個工作表。

- 六項 SPS：觀察、分類、設計探究、進行實驗、推論、溝通，各 4 分，合共 24 分。
- 新知識學習：從學生學習反思評估蒸騰及氣孔、木質部及蒸騰拉力、光強度影響、運用概念與數據修訂原始假說，各 2 分，合共 8 分。原始假說正確的學生可以透過完善解釋得滿分。
- 整體分數：SPS + 新知識，滿分 32。九個人工評分格全部填妥，而且學生已提交反思，才顯示整體分數；空白顯示待評，填 0 才當作零分。
- 初步觀察、假說理由、對照方案、裝置方案及書面表達由教師評分；反思四項也由教師評分，不以關鍵字出現次數代替理解。
- 自動項目採最後確認答案。讀數容差 ±0.25 cm；速度按學生自己讀數計算：新紀錄保留兩位小數，容差 0.0051 cm/min；舊紀錄維持三位小數及 0.00051 容差；標點按學生自己的速度計算檢核，避免重複扣算術錯誤。完整量度輪次與點擊次數分開。
- 格子底色區分 SPS／新知識類別。綠字＝正確或滿分，紅字＝錯誤或零分，橙字＝部分得分；未答／未評為中性色。開放題格子會隨 Excel 教師填分自動變色。表頭凍結，可篩選；人工格設整數配分範圍驗證。
- 用 Excel 開啟會重新計算公式。教師填分後保存該檔；瀏覽器不會讀取老師在 Excel 填的分數，重新下載將產生新的待評檔。

「評分準則」逐項列出滿分、部分得分及零分條件。這是活動評分初稿，正式比較四個模組前需統一 rubric、配分與評分者校準，不作為已驗證的 SPSAI 替代工具。
